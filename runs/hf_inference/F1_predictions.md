## I.5 — floor'ы (гейт)

Промпт: "The capital of France is", токенизация с BOS.
Референс: transformers 4.55.0, torch 2.8.0 CPU, torch_dtype=float32.
Наш путь: fwdLlamaHFF64, чистый F64, те же веса (BF16 -> F32/F64, оба
расширения битово точны — веса идентичны референсным).

1. **Токенизация промпта == input_ids референса** (бинарный floor, гейт).
2. **Top-10 логитов: множество И порядок id совпадают** (бинарный floor, гейт).
3. **rel = |ours - ref| / max(1, |ref|) <= 1e-3** для каждого из top-10
   и первых 8 логитов строки (гейт).

## I.5 — прогнозы (не гейты, проверка калибровки)

- **Ожидаемый класс worst rel: ~1e-4** (одна декада запаса до floor).
  Обоснование: расхождение только компьют-точность F32 (HF) против F64 (наш);
  скалярное произведение длины D=2048 в F32 даёт rel ~sqrt(D)*2^-24 ≈ 2.7e-6
  на элемент matmul; 22 слоя резидуального тракта + RMSNorm-деления
  амплифицируют на 1-2 декады => 1e-5..1e-4 на логитах (|логит| ~ 5-20).
  Класс 1e-3 из карточки — консервативный floor с запасом.
- **Greedy next token — "Paris"** (с ведущим пробелом-метапробелом ▁Paris):
  фактологический промпт, базовая модель 1.1B должна отвечать столицей.
- Время загрузки весов (8.8GB F64 из BF16): 10-60 c.
  Время forward 7 токенов на одном CPU-потоке: 20-120 c
  (доминируют 22*3 SwiGLU-matmul D=2048,F=5632; ~14 GFLOP F64).
  Это линейка, не продукт — скорость не гейт и не замер (Фаза I).

## ТЗ-02 отрицательный контроль (записано ДО прогона, 2026-08-03)

Проба инъективности гейта I.5: порча ОДНОГО элемента весов на своей копии —
`Layers[0].Wq[0] += 1.0` (аддитивно: не зависит от собственной магнитуды
элемента, класс весов ~0.02, т.е. порча ~50× типового веса; слой 0 —
возмущение проходит все 22 слоя).

**Floor (гейт):** worst rel (то же множество top-10 + first8, та же формула)
ОБЯЗАН ПРЕВЫСИТЬ 1e-3; тест ассертит превышение, не прохождение.

**Прогноз величины (до прогона):** класс 1e-2..1e-1.
Обоснование: +1.0 к Wq[out=0][in=0] слоя 0 сдвигает q-компоненту головы 0
на ~xn[0]=O(1) при типовых |q|=O(1) => скоры головы 0 сдвигаются на O(1)
единиц до softmax => перераспределение внимания головы 0 заметно меняет её
вклад в резидуальный тракт; разбавление 1/32 голов и 22 слоя нелинейной
прокачки дают итог на логитах класса 1e-2..1e-1 при |логит|~10.
Нижняя граница уверенности: >=1e-3 (собственно floor контроля).

### Попытка А — ПРОГНОЗ-ПРОМАХ (записано ПОСЛЕ прогона А, до прогона Б)

Факт (raw: raw_f1hf/i5_negative_control_attemptA.txt): worst rel = 5.082e-07
при прогнозе 1e-2..1e-1 — промах на ~5 декад в ОПАСНУЮ сторону (порча
невидима гейту). Forward пересчитался честно (логиты сдвинулись в 7-м
знаке против чистого прогона: 1.910e-07 на rank-0 против 2.322e-07), но
эффект утонул. Разбор: ключевая ошибка прогноза — «xn[0]=O(1)»; реальный
вклад Δq[0] = 1.0·xn[i][0] прошёл через цепочку гашений: одна компонента
из hd=64 в скалярном произведении со k (÷8 scale), softmax по S=6 позиций
на почти неизменных скорах, голова 1/32 в Wo-миксе, RMSNorm-ренормализация
каждого из 22 слоёв. Одноэлементная порча ГЛУБИННОГО веса — негодный
инструмент отрицательного контроля: трансформер к ней робастен.
Урок: контрольное возмущение обязано иметь АНАЛИТИЧЕСКИ прямой путь к
сравниваемой величине, без softmax/нормализаций между порчей и логитом.

## ТЗ-02 отрицательный контроль, попытка Б (записано ДО прогона Б)

Возмущение: `LMHead[ArgmaxID(=3681)*D + 0] += 100.0` — одно значение,
строка lm_head токена "Paris", входная размерность 0.
Путь к логиту ПРЯМОЙ и последний в тракте: logits[3681] = Σ_j xn_final[j] ·
LMHead[3681][j], т.е. Δlogit(Paris) = 100.0 · xn_final[0] — ни softmax, ни
нормализаций, ни голов между порчей и сравниваемым числом.

**Floor (гейт, тот же):** worst rel ОБЯЗАН превысить 1e-3.

**Прогноз величины (до прогона):** rel(rank-0) = 100·|xn_final[0]| / 13.39.
Класс |xn_final[j]| для RMS-нормированного вектора с обученной gamma:
0.1..3 => rel класса **0.7..22** (точечно ~7 при |xn_final[0]|~1).
Страховочная нижняя граница: даже при |xn_final[0]| ~ 1.5e-4 rel был бы
1.1e-3 > floor; величина добавки 100.0 выбрана именно чтобы floor
пробивался во всём правдоподобном диапазоне компоненты.
