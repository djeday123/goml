## I.5 — floor'ы (гейт)

Промпт: "The capital of France is", токенизация с BOS.
Референс: transformers 4.55.0, torch 2.8.0 CPU, torch_dtype=float32.
Наш путь: fwdLlamaHFF64, чистый F64, те же веса (BF16 -> F32/F64, оба
расширения битово точны — веса идентичны референсным).

1. **Токенизация промпта == input_ids референса** (бинарный floor, гейт).
2. **Top-10 логитов: множество И порядок id совпадают** (бинарный floor, гейт).
3. **rel = |ours - ref| / max(1, |ref|) <= 1e-3** для каждого из top-10
   и первых 8 логитов строки (гейт).

## I.5 — прогнозы (не гейты, проверка калибровки)

- **Ожидаемый класс worst rel: ~1e-4** (одна декада запаса до floor).
  Обоснование: расхождение только компьют-точность F32 (HF) против F64 (наш);
  скалярное произведение длины D=2048 в F32 даёт rel ~sqrt(D)*2^-24 ≈ 2.7e-6
  на элемент matmul; 22 слоя резидуального тракта + RMSNorm-деления
  амплифицируют на 1-2 декады => 1e-5..1e-4 на логитах (|логит| ~ 5-20).
  Класс 1e-3 из карточки — консервативный floor с запасом.
- **Greedy next token — "Paris"** (с ведущим пробелом-метапробелом ▁Paris):
  фактологический промпт, базовая модель 1.1B должна отвечать столицей.
- Время загрузки весов (8.8GB F64 из BF16): 10-60 c.
  Время forward 7 токенов на одном CPU-потоке: 20-120 c
  (доминируют 22*3 SwiGLU-matmul D=2048,F=5632; ~14 GFLOP F64).
  Это линейка, не продукт — скорость не гейт и не замер (Фаза I).

## Зачем max(1,|ref|) в знаменателе

Логиты около нуля дают взрыв относительной ошибки без смысловой нагрузки;
клип знаменателя единицей — стандарт линейки A-LLM (floor против |ana_F64|).
